# 戴尔 PN7522W 侧键桥接模块

本模块让已验证的小米平板 6 Pro 在本机读取戴尔 PN7522W 的两个侧键，
并把按下/松开交给原版“焦点笔 Plus”处理。运行不依赖电脑或 USB。
配置单击、长按、双击及按应用动作，仍使用“焦点笔 Plus”的界面。

## 安装

1. 保留已安装的 KernelSU、Zygisk Next、LSPosed 和“焦点笔 Plus”。
2. 确认“焦点笔 Plus”已在 LSPosed 启用，作用域勾选“系统框架”。
3. 在 KernelSU 管理器的模块页面选择本 ZIP，安装后重启。
4. 在“焦点笔 Plus”里配置：上侧键（离笔尖较远）对应“笔键 1”，
   下侧键（靠近笔尖）对应“笔键 2”。

只要模块运行，笔尖在屏幕感应范围内即可测试。当前版本没有证明远离屏幕后能读取侧键。
未配置动作的手势不会执行；例如双击设为“不执行”时，连按两次可能没有动作。
长按和双击各按一个手势处理，不等于持续重复触发。

## 暂停、恢复、卸载

- 点击本模块的“动作”按钮：第一次暂停，再次点击恢复。暂停状态会保留至下次开机。
- 在 KernelSU 禁用模块时，本模块会自行停止；重新启用后重启以恢复。
- 在 KernelSU 卸载模块后重启。停止时释放所有按键，移除本模块自己的采样点和虚拟设备。
- 模块不修改 boot、vendor 分区、触控驱动文件或“焦点笔 Plus”的 APK 和配置。

## 原理与限制

当前驱动已经读到了戴尔侧键状态，但没有把它们作为标准按键上报。
模块使用私有采样点读取正式笔处理路径的按钮字节，创建只含两个按键的虚拟输入设备，
由“焦点笔 Plus”执行自定义动作。真实按压时长会保留；原有坐标、压力、倾角路径不被替换。

离笔、无有效数据或停止服务时会释放按键；旧记录不会在唤醒后重新当成按下。
内核采样只针对这套驱动，运行时仍有额外开销，长期待机耗电没有经过完整测量。
状态和简短日志保存在内存目录 `/dev/dell_pen_bridge_liuqin`，不持续保存笔迹或坐标。

“焦点笔 Plus”需要继续启用。本模块不独立实现动作界面，也不增加原应用没有的橡皮擦功能。
连接小米官方笔或运行旧的电脑临时测试程序前，应先暂停本模块，以免同名设备发生冲突。

## 诊断与源代码

包内 `src/dell_pen_bridge.c` 是本机程序源码，`bin/*.sh` 是启动和停止脚本。
查看状态：以 Root 运行 `sh /data/adb/modules/dell_pen_bridge_liuqin/bin/control.sh status`。
启动失败时可查看 `/dev/dell_pen_bridge_liuqin/run.log`；该日志不包含原始笔迹数据。

本模块是本地适配，不是戴尔、小米、KernelSU 或“焦点笔 Plus”作者发布的官方组件。
